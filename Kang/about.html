WELCOME TO KANG 工

📚 What is Kang?

Kang (工) means "work" — derived from the Teochew word Kang, also written as 工 gōng in Mandarin. This site is a static online portfolio / resume built with HTML and CSS, hosted free on GitHub Pages.

It started in October 2022 as a way to refresh HTML & CSS skills, and has since evolved into a data collection experiment tracking visitor analytics.

📊 Data & Analytics

This site collects anonymised web traffic data — device type, location, and browsing behaviour — via Google Analytics.

That data powers two dashboards:

  • Google Data Studio report — live traffic overview
  • Tableau dashboard — event tracking via API download
