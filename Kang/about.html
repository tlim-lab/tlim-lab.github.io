This site is called Kang — it means work.

Kang (工) is derived from the Teochew word Kang, written as 工 gōng in Mandarin. It started in October 2022 as a way to refresh HTML & CSS skills, and grew into a data analytics experiment tracking visitor behaviour.

Built with plain HTML and CSS — no frameworks, no build step. Hosted free on GitHub Pages.
